2040 PROJECTION METHOD
This dashboard does not run a machine-learning forecasting model. The 2040 projection shown elsewhere in the app is a deterministic ordinary least-squares (OLS) trend fit to the observed 2000-2024 annual indices, with a 95% band derived from historical residuals — labelled INDICATIVE, not a model prediction. A physically-based future scenario requires the CMIP6 Earth Engine workflow (scripts/05_gee_cmip6_2040.js, 06_convert_gee_export.py), which must be run explicitly — see docs/METHODOLOGY.md §5.
SATELLITE ANALYTICS PANEL
Not available yet
Sentinel-2/MODIS/SMAP/VIIRS/ERA5 layers are not integrated into this dashboard. This panel previously showed fixed placeholder values (NDVI, EVI, LST, soil moisture, etc.) that were never sourced from any real satellite feed -- removed, see docs/AUDIT_2026-08-01.md. Real NDVI is available today in the NDVI Analytics panel (UNDP DiCRA, district-level).
API ACCESS
No public API yet
This portal has no backend and serves static files from GitHub Pages. The endpoints previously listed here (/api/v1/...) do not exist and were never implemented -- removed, see docs/AUDIT_2026-08-01.md. The underlying data files themselves are public: dashboard/data/*.json in the repository.
PANCHAYAT VULNERABILITY RANKING
Not available yet
No panchayat-level vulnerability assessment has been computed. This panel previously listed named Gram Panchayats (Alirajpur, Badwah, Bijori and others) with invented vulnerability scores that were never based on any real assessment -- removed, see docs/AUDIT_2026-08-01.md. A real ranking would need panchayat-level boundaries and indices, which are not yet integrated (see docs/NATIONAL_SCALE_RESEARCH.md).
FOREST & TRIBAL ANALYTICS
Not available yet
Forest Survey of India / Bhuvan land-use data is not integrated. This panel previously named specific districts (Umaria, Shahdol, Mandla and others) with invented risk levels and carbon-stock figures -- removed, see docs/AUDIT_2026-08-01.md. See the Biodiversity Risk panel for the current honest "Not available" state on forest cover and biodiversity.
PMFBY INSURANCE ANALYTICS
Not available yet
No PMFBY enrollment or claims data is integrated. This panel previously showed invented enrollment, claim-exposure and "AI risk score" figures -- removed, see docs/AUDIT_2026-08-01.md. PMFBY publishes scheme data via data.gov.in; integrating it is tracked in docs/DATA_SOURCES.md.
VILLAGE INTELLIGENCE
Use the Location Selector
Village-level IMD indices for the 5 covered districts (Bhopal, Indore, Jabalpur, Rewa, Sidhi) are shown in the Historical Indices panel once you pick District → Block → Village from the Location Selector on the map. Village names for the rest of India are listed there too (see dashboard/data/boundaries/), but climate indices only exist for the 5 covered districts -- other villages show "Data not yet available".
